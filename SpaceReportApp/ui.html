Run as administrator?

Space Report works fine without it — every file on your drive is still found.
What you won’t see is the protected system-cleanup areas: Delivery Optimization, kernel telemetry dumps, the Windows Search index and Defender’s scan history. Windows blocks ordinary programs from measuring those, and they are commonly several GB between them.
Choosing yes restarts the app and asks Windows for permission. You will need to run the scan again.
